# Proxy Share v1.0.1

## 新增

- 主窗口标题显示版本号 `v1.0.1`，也可在 Windows 文件属性中查看产品版本。
- 支持从下拉菜单切换代理主机。可添加、编辑和删除自定义主机，内置主机保留在下拉列表中。自定义主机保存在 Windows 的“文档\ProxyShare”目录中，替换 EXE 后仍可使用。
- 支持批量测试各主机通过代理访问 Google 的延迟，结果显示在下拉列表中。单独测试所选主机也会显示延迟。
- 显示系统代理与所选主机不一致的状态，并在启动时提示检测到的其他代理软件。主开关支持用 Tab 聚焦，用空格或 Enter 切换。

## 修复

- 修复早期构建在初始化或缩放时偶发的 `DropDownWidth` 为 `0` 异常，下拉列表随选择框调整宽度。
- 切换主机后立即重新读取系统代理，让开关反映实际启用状态。
- 修复深浅主题下圆角按钮首次绘制和缩放时的背景残影。

## 构建与发布

- 本地构建与测试共用同一套编译配置，版本号统一写入 EXE 元数据。
- 发布流程核对版本号、tag 和本次更新说明，通过测试后上传 EXE、ZIP 压缩包和 SHA-256 校验文件。

## 升级

关闭旧程序，下载本页的 `ProxyShare.exe` 或解压 `ProxyShare-v1.0.1-windows.zip`，替换原 EXE。启动后确认窗口标题显示 `v1.0.1`。如果旧快捷方式仍打开旧版本，将它指向新 EXE。

从 `v1.0.0` 升级时，原先写在注册表中的代理地址和端口需要在「编辑」中重新添加。若已使用保存自定义主机的中间构建，现有文档目录中的主机数据会保留或迁移。关闭软件窗口会保留当前系统代理设置，关闭主开关才会恢复接管前的设置。
